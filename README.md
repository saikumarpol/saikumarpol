# 🚀 Featured Projects

## 🩺 Mother & Child Health Assessment App

### AI-Powered Anemia Screening

A mobile health assessment application designed for anemia screening, particularly for rural and underserved populations.

- Built the complete **React Native Android application** from scratch.
- Implemented real-time camera processing using **React Native Vision Camera and frame processors**.
- Integrated two **TensorFlow Lite (.tflite) Computer Vision models** for the assessment workflow.
- Implemented a two-stage pipeline where the first model detects the **conjunctiva**, followed by automatic image capture and anemia assessment.
- Implemented image preprocessing including **320×320 frame resizing and 512×512 cropping** before model inference.
- Integrated **on-device AI inference**, executing model inference directly on the mobile device.
- Generated **Hb values and severity classification** including Normal, Anemic and Grossly Anemic.
- Built backend services using **Node.js**, with **MongoDB and MinIO** for data and image storage.
- Currently being field tested on Android devices.

**Tech:** React Native • React Native Vision Camera • TensorFlow Lite • Computer Vision • Node.js • MongoDB • MinIO
